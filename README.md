# Pihow Services

Production web application for **Pihow Services** — Full-Stack Web Development, SaaS Platforms, and Enterprise Data Engineering & Analytics.

## Tech Stack
- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **UI & Styling:** React 19, TypeScript, [Tailwind CSS 4](https://tailwindcss.com/)
- **Icons:** Lucide React
- **Typography:** Fraunces, Inter, IBM Plex Mono

## Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

## Production Build
```bash
npm run build
npm run start
```
